# Customer Segmentation Analysis

## Overview
This project analyses customer transaction data to identify high, medium, and low-value customers.

## Tools Used
- SQL (SQLite)
- Python (Pandas, Matplotlib)

## Key Insights
- Majority of customers are low-value (62%)
- Medium-value customers generate the most revenue overall
- UK dominates revenue, with limited international contribution

## Files
- customers.csv
- transactions.csv
- analysis.ipynb
